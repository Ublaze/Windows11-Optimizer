## [1.0.0] - 2026-03-08

### Added
- Initial release: all-in-one Windows 11 optimizer script
- System info gathering and baseline stats
- Automatic System Restore point creation
- Disk cleanup (temp files, caches, Windows Update, Recycle Bin)
- Startup app management (Docker, Chrome/Edge auto-launch, etc.)
- Service optimization (Xbox, Telemetry, Fax, Maps, Insider)
- Registry tweaks (faster boot, snappier menus, disable Cortana/Bing/ads)
- Telemetry scheduled task disabling
- TCP network optimization and Wi-Fi Sense disabling
- High Performance power plan activation
- Security scan (unsigned process check, Defender status)
- `-SkipRestore` and `-Silent` flags
- One-liner download-and-run command
- Before & after performance comparison output
